# Tweeter-Project
Twitter Analytics Dashboard (Power BI)

1. Project Overview:
This project is a Twitter Analytics Dashboard created using Power Bl. The project was developed during training and enhanced by completing additional internship tasks on the same dataset.
The dashboard provides insights into tweet engagement, media interactions, impressions, likes, retweets, replies, and user activity through interactive reports and visualizations.

2. Tools Used:
•Microsoft Power BI
•Power Query
•DAX

3. Dataset:
The dataset contains the following information:
•Tweet text
•Likes
•Retweets
•Replies
•Media views
•Media engagements
•Impressions
•URL clicks
•User profile clicks
•Engagement rate
•Date and time information


4.Dashboard Tasks:

Task 1 - Tweet Interaction Breakdown by Category
•URL clicks
•User profile clicks
•Hashtag clicks
Applied required filters


Task 2 - Engagement Rate Comparison
•Compared tweets with app opens and without app opens
Applied all required conditions


Task 3 - Media Interaction by Day of Week
•Created a dual-axis chart
•Highlighted spikes in engagement

Task 4 - Replies, Retweets, and Likes Comparison
•Compared engagement metrics from June to August 2020

Task 5 - Monthly Engagement Rate Trend
•Compared tweets with media and without media

Task 6 - Top 10 Tweets by Engagement
•Identified the top-performing tweets
Applied all required filters and conditions

•Interactive dashboards
